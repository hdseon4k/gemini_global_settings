# Gemini Global Settings 🤖✨

이 저장소는 Gemini IDE 에이전트의 **전역 설정(Global Config)**, 커스텀 룰, 그리고 행동 지침을 여러 기기에서 완벽하게 동기화하기 위한 저장소입니다.
회사 PC, 개인 노트북 등 다양한 환경에서 에이전트를 동일한 상태(규칙, 스킬 등)로 유지하기 위해 사용됩니다.

## 🚀 새로운 PC에 동기화(Clone) 하는 방법

다른 PC에서 이 설정들을 그대로 가져와서 적용하려면 터미널(CMD/PowerShell)을 열고 아래 명령어를 순서대로 실행해 주세요.

### 1. 에이전트 전역 폴더로 이동
`ash
# 윈도우 기준, 사용자 홈 디렉터리 아래의 .gemini 폴더로 이동합니다.
cd C:\Users\%USERNAME%\.gemini

# 만약 기존에 임시로 생성된 config 폴더가 있다면 이름을 변경하거나 삭제합니다.
# (예: rename config config_backup)
`

### 2. 저장소 Clone 하기
`ash
# 반드시 'config' 라는 이름의 폴더로 저장소를 복제해야 IDE가 정상적으로 인식합니다.
git clone https://github.com/hdseon4k/gemini_global_settings.git config
`

### 3. 완료! 🎉
이제 새로운 PC의 에이전트(Gemini)가 즉시 이 저장소에 등록된 AGENTS.md (전역 행동 규칙)와 플러그인들을 바탕으로 똑같이 영리하게 동작합니다. 

---

## 📁 주요 구조 설명
* **AGENTS.md**: 에이전트가 어떤 상황에서 어떻게 행동해야 하는지에 대한 '전역 자동화 트리거'와 '제약 사항'이 선언된 핵심 헌장입니다. (예: 세션 종료 시 문서 자동 아카이빙 등)
* **GEMINI프로젝트_관리방법.md**: 사람(개발자)을 위한 매뉴얼로, 에이전트에게 어떤 프롬프트를 내리면 되는지 정리해 둔 사용 예제집입니다.
* **plugins/ & skills/**: 에이전트의 능력을 확장해 주는 커스텀 워크플로우와 도구 모음입니다.
